# Инструкция: Claude Code на своём VPS

Пошаговая установка веб-панели CloudCLI и Claude Code на чистый сервер. После этого панель открывается как обычный сайт, постоянный VPN не нужен.

Нужна подписка **Claude Pro**. Один аккаунт Claude — один сервер, чужим доступ не раздавайте.

## Что получится

```
браузер  →  https://ai.ваш-домен  →  Caddy (HTTPS)
                                      →  CloudCLI (порт 3001)
                                      →  Claude Code на VPS
```

С телефона и компьютера заходите по своему адресу. Anthropic видит европейский IP сервера.

## Что нужно заранее

| Вещь | Минимум |
|------|---------|
| VPS | Ubuntu 22.04 или 24.04, **4 ГБ RAM**, 5 ГБ на диске, локация вне РФ (например DE/NL) |
| Домен | свой, можно поддомен `ai` у уже купленного имени |
| Доступ | `ssh root@IP` (пароль или ключ) |
| Подписка | Claude Pro |
| Почта | любая, только для сертификата Let’s Encrypt |

Порты **22, 80, 443** должны быть открыты у хостера.

Не ставьте это на сервер, где уже крутится Hiddify или другой веб-сервер на 80/443.

## 1. Заказать VPS

1. Создайте сервер: Ubuntu 22.04/24.04, от 4 ГБ памяти.
2. Из письма хостера возьмите **IP** и пароль (или ключ) root.
3. Не используйте этот IP в публичных чатах и в git.

## 2. Привязать домен

В DNS регистратора добавьте A-запись:

- тип: **A**
- имя: `ai` (получится `ai.ваш-домен`)
- значение: IP сервера

Установщик сам дождётся, пока запись начнёт отвечать. Ждать вручную не обязательно.

## 3. Подключиться по SSH

С своего компьютера:

```bash
ssh root@IP_СЕРВЕРА
```

В первый раз напишите `yes`. Пароль при вводе не отображается — это нормально.

Приглашение должно быть вида `root@...#`. Дальше все команды — **на сервере**.

## 4. Запустить установщик

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/sashik08/cloudcli-installer/main/install.sh)"
```

Ответы:

1. **Какой ИИ** — `1` (Claude). Codex можно добавить позже той же командой.
2. **Домен** — например `ai.example.com` (без `https://`).
3. **Почта** — для сертификата.

Дальше скрипт ставит Node.js 22, Claude Code, панель CloudCLI, Caddy, UFW и Fail2Ban (около 13 шагов).

Неинтерактивно:

```bash
AGENT=claude DOMAIN=ai.example.com EMAIL=you@example.com \
  bash -c "$(curl -fsSL https://raw.githubusercontent.com/sashik08/cloudcli-installer/main/install.sh)"
```

Сначала можно прогнать без установок (на любой машине):

```bash
DRY_RUN=1 AGENT=claude DOMAIN=ai.example.test EMAIL=dev@example.test \
  bash -c "$(curl -fsSL https://raw.githubusercontent.com/sashik08/cloudcli-installer/main/install.sh)"
```

## 5. Подключить аккаунт Claude

В конце установщик предложит три варианта.

**Перенос с компьютера (без VPN).** Если Claude Code уже установлен у вас локально, во **втором** терминале (не на сервере) выполните команду `scp`, которую покажет скрипт. Она копирует `~/.claude/.credentials.json` на сервер. Затем на сервере нажмите Enter.

**Вход в браузере.** Нужен VPN на одну минуту: откройте ссылку Anthropic, авторизуйтесь, вставьте код обратно в терминал. VPN после этого выключите.

**Пропустить.** Позже на сервере: `ai-login`.

## 6. Сохранить доступ к панели

В конце будут три строки: адрес, логин `admin`, пароль. Пароль больше на экране не повторится.

Копия на сервере:

```bash
cat /root/claude-server-info.txt
```

Новый пароль: `ai-password`.

## 7. Первый вход

1. Откройте `https://ai.ваш-домен` **без VPN**.
2. Войдите как `admin`.
3. Укажите имя и email для Git, если панель спросит.
4. Claude должен быть Authenticated. Нажмите Complete Setup.

Создайте проект: **Create New Project**, путь только внутри `/workspace`, например `/workspace/moy-proekt`. Поле GitHub URL можно оставить пустым.

Проверка: напишите в чате проекта «создай файл test.txt». Файл должен появиться в этой папке.

## 8. Команды на сервере

| Команда | Зачем |
|---------|--------|
| `ai-status` | панель, Caddy, вход в Claude |
| `ai-login` | подключить или перевойти в аккаунт |
| `ai-update` | обновить панель и Claude Code |
| `ai-password` | сбросить пароль панели |
| `ai-uninstall` | снять установку |

Добавить ChatGPT Codex рядом: снова запустить ту же `curl`-команду и согласиться.

## Если что-то пошло не так

- **Долго «жду домен»** — проверьте A-запись. Можно подождать до часа; установщик крутится сам.
- **Сайт не открывается** — порты 80/443 у хостера, затем `ai-status`. Иногда сертификат выходит за 5 минут.
- **Панель есть, Claude молчит** — `ai-login`.
- **Забыли пароль** — `cat /root/claude-server-info.txt` или `ai-password`.
- **Лог установки** — `tail -40 /var/log/claude-server-install.log`.
